2. 物理按钮 / 旋钮 → 功能（AXI GPIO 与 gpio-keys）

设备树 21 位 AXI GPIO（brass-common.dtsi:130-136）+ gpio-keys（pwrbtn_on）+ 3 个 rotary 编码器（brass-common.dtsi:212-234）。

物理输入GPIO 位 / 键码软件功能 / 行为证据
电源键 pwrbtn_onbit13 / KEY_POWER开机：启动校验 power_boot_hold_check()（默认仅记录不误关）。短按：背光开关 backlight_switch()。长按(≥1s)：关机 power_shutdown() → 落盘 reboot(RB_POWER_OFF)（当前设备树无断电驱动，仅 halt 不断电）。power.c:109-167；main_screen.c:279-287
PTT ptt_inbit17 / KEY_CONNECT收发切换：MSG_PTT → radio_set_ptt() 置 tx_out=1、preamp_on=0，发 MSG_TX/MSG_RX。keypad.c:44-46；radio.c:489-512
编码器1 enc1_a/bbit6/7 → event0音量/增益旋钮 vol（div=1）。旋转 → 音量/增益 ±1；其"按下"来自面板键 BTN_NORTH（EDIT/SELECT 切换）。main.c:130；main_screen.c:644-662
编码器2 enc2_a/bbit8/9 → event1多功能旋钮 MFK（LVGL ENCODER 设备）。旋转导航/编辑 MFK 菜单；其"按下"来自面板键 BTN_SOUTH。main.c:131；mfk.c:31-475
编码器3 (PS gpio0 12/13)rotary@2 → event2主频率调谐旋钮 main（div=8）。旋转 → freq_shift() 频率步进。无按下映射。main.c:132；main_screen.c:534-618
preamp_onbit19gpiod 输出线；由 radio_set_ptt 控制：RX 开 / TX 关（前置放大使能）。hw/gpio.c:85,194-198；radio.c:500,506
tx_outbit20gpiod 输出线；PTT 时置 1，切换 HF/VHF/UHF TX 路由继电器。hw/gpio.c:86,200-223
cw_dotbit15设备树有定义，GUI 未读取；CW 点键发报由 FPGA/MicroBlaze 处理。radio.c:520-521
cw_dashbit16同上，GUI 未读取。—
user2/3/4/5/6/8bit0-5设备树"用户 LED/IO"，GUI 无消费者（预留）。—
ext_pin1bit14设备树"外部引脚"，GUI 未使用。—
adc_dith / adc_pga / adc_ofabit10/11/12ADC 抖动/PGA/溢出；GUI 未作为 GPIO 读（ADC 经 FPGA 寄存器）。fpga/adc.c
charge_pumpbit18仅 hw/xvrt.c 中作为 ADF 合成器寄存器宏，非 GPIO 消费。hw/xvrt.c:30,70

4. 屏幕软键盘 HKEY（触摸/矩阵，非 AXI GPIO）

hkey.c 7×5 矩阵，用于数字/频率输入与内存操作。

键功能
HKEY_1..9内存载入/保存
HKEY_UP / HKEY_DOWN频率 ±1（短按）/ 长按换 band
HKEY_P1..P4 / HKEY_A..Doptions->hkeys 自定义动作

5. 未使用 / 未确认项

项状态
cw_dot (bit15) / cw_dash (bit16)设备树有，GUI 未读；CW 发报在 FPGA/MB 侧，radio_set_morse_key() 为空桩。
user2..user8 (bit0-5)预留，GUI 无消费者。
ext_pin1 (bit14)未使用。
adc_dith/pga/ofa (bit10-12)ADC 经 FPGA 寄存器，GUI 未作为 GPIO 读。
charge_pump (bit18)仅 ADF 寄存器宏，非 GPIO。
SWR 扫描对话框对话框与按钮存在，但 main_screen_action() 无对应分支，触发未接好。
